# اپ مشتریان رادین – نسخه ۰٫۲

این بسته نخستین رابط مشتریِ قابل نصب به‌صورت PWA است. روی Android با مرورگر Chrome و پس از میزبانی روی HTTPS، مشتری می‌تواند از گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» استفاده کند. این بسته APK نیست.

## امکانات پیاده‌سازی‌شده
- طراحی فارسی و راست‌چین با هویت مشکی/نارنجی رادین
- نمایش کاتالوگ واقعی از API مسیرهای `/public/products` و `/public/categories`
- جست‌وجو و فیلتر دسته‌بندی
- نمایش تنوع، قیمت خرده‌فروشی و موجودی
- سبد خرید محلی با ذخیره در مرورگر
- فرم دریافت نام، موبایل و نشانی تحویل
- ارسال درخواست سفارش به API با شناسه تنوع و تعداد؛ قیمت نهایی فقط در سرور محاسبه می‌شود
- ثبت سفارش با وضعیت «در انتظار بررسی» و «پرداخت‌نشده»؛ کاهش موجودی به‌صورت تراکنشی و بازگشت موجودی هنگام لغو توسط پنل
- manifest و service worker برای نصب PWA و نگهداری فایل‌های رابط
- عدم نمایش قیمت عمده و بهای خرید؛ API عمومی نیز این فیلدها را برنمی‌گرداند

## اتصال به API
در `config.js` مقدار `API_BASE_URL` را به نشانی HTTPS سرور واقعی تغییر دهید. نمونه:

```js
window.RADIN_CONFIG = { API_BASE_URL: "https://api.your-domain.example" };
```

سپس دامنه رابط مشتری را در `CORS_ORIGIN` بک‌اند مجاز کنید. فایل‌ها باید روی HTTPS یا localhost میزبانی شوند تا نصب PWA و service worker فعال شود.

## ثبت سفارش در نسخه ۰٫۲
فرم تسویه، نام و موبایل مشتری، شهر، نشانی و اقلام سبد را ارسال می‌کند. مبلغ و قیمت‌ها از سمت مرورگر پذیرفته نمی‌شوند؛ سرور قیمت جاری را از دیتابیس می‌خواند. سفارش با وضعیت `PENDING_REVIEW` و پرداخت `UNPAID` ایجاد می‌شود. این نسخه درگاه پرداخت ندارد و فقط درخواست سفارش برای تماس و تأیید فروشگاه ثبت می‌کند. API برای مشاهده سفارش‌ها مسیر `/admin/orders` و برای تغییر وضعیت مسیر `/admin/orders/:id/status` دارد؛ این مسیرها به توکن کارکنان نیاز دارند. لغو سفارش، موجودی رزروشده را به انبار برمی‌گرداند.

## وضعیت فعلی و محدودیت‌ها
- این نسخه APK نیست؛ PWA قابل نصب از مرورگر است.
- سبد خرید فعلاً فقط در دستگاه مشتری ذخیره می‌شود.
- پرداخت آنلاین، ورود با OTP، حساب عمده، تخفیف وفاداری، استعلام قیمت و پیگیری سفارش مشتری هنوز پیاده‌سازی نشده‌اند. ثبت درخواست سفارش به API اضافه شده، اما فقط پس از راه‌اندازی دیتابیس و API و تنظیم نشانی آن کار می‌کند.
- تصاویر محصول در API فعلی وجود ندارند؛ در نسخه بعدی باید بارگذاری/مدیریت تصویر امن اضافه شود.
- تا زمانی که API روی سرور HTTPS واقعی نصب و تنظیم نشود، کاتالوگ زنده نمایش داده نمی‌شود.

## اجرای آزمایشی محلی
برای مشاهده رابط، یک سرور فایل محلی اجرا کنید؛ مثلاً با Node.js:

```bash
npx serve .
```

برای استفاده عمومی باید روی دامنه HTTPS منتشر شود و `config.js` به API واقعی اشاره کند.
